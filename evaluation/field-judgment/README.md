# 현장 문장 채점 묶음

판정 도구(`evaluate_observation`)를 현장 문장으로 재는 자료입니다.

## 어떻게 만들었나
- 문장과 정답은 이 저장소의 코드를 보지 않은 작성자가 판정 규칙만 받아 썼습니다(2026-11-16, AI 작성. 묶음마다 다른 작성자).
- 실제 현장에서 수집한 문장이 아닙니다. 실제 사용자의 문장을 모으면 이 자리에 묶음으로 더합니다.

## 파일
| 파일 | 쓰임 |
|---|---|
| `seen.json` | 지금까지 받은 문장 전부(묶음 넷). 처음 돌린 뒤에는 결과를 보며 판정 코드를 고쳤으므로 점수가 높게 나옵니다 — 회귀 시험으로 씁니다 |
| `history.json` | 묶음마다 **처음 돌렸을 때**의 결과. 처음 보는 문장에서 얼마나 맞는지는 이 기록으로만 말합니다 |

새 묶음은 받은 직후 한 번 돌려 `history.json` 에 적은 다음 `seen.json` 에 합칩니다. 그 순서를 바꾸면(먼저 보고 고친 뒤 돌리면) 처음 보는 문장의 수치가 아닙니다.

## 항목
```json
{ "id": "h01", "test": "slump|air|compaction|chloride|strength", "sentence": "…", "expected": "PASS|FAIL|ASK", "why": "정답의 계산" }
```
- `ASK` 는 도구가 판정하지 않고 되물어야 하는 문장입니다 — 같은 시험의 측정값이 둘 이상이거나, 판정에 필요한 정보(호칭 슬럼프·호칭강도 등)가 없습니다. 도구는 한 번에 값 하나를 판정합니다. AI 비서는 값마다 도구를 따로 불러 모두 판정합니다.
- 정답 규칙: 슬럼프는 호칭 슬럼프별 허용오차(25 → ±10, 50·65 → ±15, 80 이상 → ±25), 공기량 4.5±1.5 %, 노상 다짐도 95 % 이상, 염화물 0.30 kg/㎥ 이하, 압축강도는 연속 3회 평균 ≥ 호칭강도이고 각 1회 시험값 ≥ 호칭강도 − 3.5 MPa(공시체 3개 평균이 1회 시험값).

## 시험
- `npm run test:field-judgment` — `seen.json` 의 문장을 도구에 그대로 넣습니다. 틀린 합격·틀린 불합격이 하나라도 나오거나 정답 수가 바닥값 아래로 내려가면 실패합니다.
- `npm run test:noise` — 같은 문장의 앞·뒤·쉼표 뒤에 측정값이 아닌 수(날짜·전화번호·차량 번호·문서 번호·회차·측점·수량)를 끼워 넣고 다시 판정합니다. 정답이 아닌 합격·불합격이 하나라도 나오면 실패합니다(되묻는 쪽으로 바뀌는 것은 허용).

## 읽는 법
문장을 도구에 그대로 넣었을 때 처음 보는 문장의 정답률은 80 % 안팎입니다(틀린 판정은 드물고, 나머지는 되묻습니다). 정해지지 않은 모양의 글을 읽는 일은 AI 비서의 몫이고, 도구의 몫은 읽어 온 값으로 틀림없이 판정하는 것과 확실하지 않을 때 판정하지 않는 것입니다. AI 비서를 거친 결과는 `history.json` 의 `assistant` 칸에 적습니다.
