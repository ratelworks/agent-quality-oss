# 현장 문장 채점 묶음

판정 도구(`evaluate_observation`)를 현장 문장으로 재는 자료입니다. `npm run test:field-judgment` 가 읽습니다.

## 어떻게 만들었나
- 문장과 정답은 이 저장소의 코드를 보지 않은 작성자가 판정 규칙만 받아 썼습니다(2026-11-16, AI 작성).
- 실제 현장에서 수집한 문장이 아닙니다. 실제 사용자의 문장을 모으면 이 자리에 묶음으로 더합니다.

## 묶음
| 파일 | 문장 | 쓰임 |
|---|---|---|
| `seen.json` | 70 | 판정 코드를 고칠 때 결과를 보며 맞춘 묶음 — 점수가 높게 나옵니다 |
| `heldout.json` | 80 | 고친 뒤에 처음 돌린 묶음 — **이 묶음의 문장을 보고 판정 코드를 맞추지 않습니다** |

`heldout.json` 의 문장에 맞춰 코드를 고치고 싶으면 그 문장을 `seen.json` 으로 옮기고, 보지 않은 문장을 새로 받아 채웁니다. 그래야 "처음 보는 문장에서 얼마나 맞는가"를 계속 잴 수 있습니다.

## 항목
```json
{ "id": "h01", "test": "slump|air|compaction|chloride|strength", "sentence": "…", "expected": "PASS|FAIL|ASK", "why": "정답의 계산" }
```
- `ASK` 는 판정하지 않고 되물어야 하는 문장입니다 — 같은 시험의 측정값이 둘 이상이거나, 판정에 필요한 정보(호칭 슬럼프·호칭강도 등)가 없습니다.
- 정답 규칙: 슬럼프는 호칭 슬럼프별 허용오차(25 → ±10, 50·65 → ±15, 80 이상 → ±25), 공기량 4.5±1.5 %, 노상 다짐도 95 % 이상, 염화물 0.30 kg/㎥ 이하, 압축강도는 연속 3회 평균 ≥ 호칭강도이고 각 1회 시험값 ≥ 호칭강도 − 3.5 MPa(공시체 3개 평균이 1회 시험값).

## 지키는 것
- 틀린 합격 0 · 틀린 불합격 0 (묶음마다)
- 정답 수가 바닥값 아래로 내려가지 않음 — 되묻기가 늘어 쓸모가 줄어드는 것을 잡습니다
