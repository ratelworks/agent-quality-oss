# 001. 법령·고시 verified 원문 내장 + 지침 조문 오인용 전면 정정

## Context

1. 법령·고시 본문은 저작권법 §7 비보호(자유 인용)인데도, 런타임 그래프의 법령 노드들은 수기 요약만 갖고 있었다 (`sourceStatus` 미지정 = unknown). 법제처 sync 산출물(조문 원문·별표 본문·서식 다운로드 링크, verified)은 `src/taxonomy/` 에만 쌓이고 **런타임이 소비하지 않았다**.
2. 런타임의 업무지침 조문 노드들이 **현행 지침(국토교통부고시 제2025-311호)과 전면 불일치**했다 — "§7 부적합 발생 시 조치"·"별지 제6호 부적합 조치결과 확인서"는 현행 지침에 **존재하지 않는 조문·서식**이었다(현행 §7 = 품질관리계획서의 작성기준, 현행 별지 제6호 = 품질검사 대행자 부적합보고서). 이 오인용이 문서 스키마 10건·도구 3종·검증 스크립트에 전파되어 있었다. "잘못된 법령 인용 차단"이 제품 존재 이유인데 자신이 오인용하는 상태.

## Decision

1. **2단 데이터 구조 확정**: 법제처 sync → `src/taxonomy/`(staging, 전량 보관) → `promote-taxonomy.ts`(명시적 매핑 테이블로 선별·병합) → `src/ontology/graph/nodes/`(runtime SSoT). 선별 기준 = 시공자 QC·감리 실무 직결만 (대행업자 평가·공장인증 서식은 staging 보관 — 검색 노이즈 방지, 올바름 > 양).
2. **verified 원문 내장**: 조문 노드에 `bodyText`(20,000자 상한 절단) + `sourceStatus: verified` + 개정 이력 + 공식 링크. 별지 서식은 원본 재배포 대신 **법제처 공식 HWP/PDF 다운로드 링크** 제공 (공공누리 4유형 준수).
3. **오인용 전면 정정**: 현행 지침 전 조문(§1~55, 편별 리셋 없음 검증) 대조로 구 노드 삭제·신 노드 생성(`guideline.art{N}`), 부적합 근거는 실존 조문 **§39(점검결과에 대한 조치)·§41(불량 자재의 처리)** 로 교체. "부적합 조치결과 확인서"는 법정 전용 서식이 없음을 명시(ISO 9001 §8.7 관행으로 정직화).

## Consequences

- verified 자산 69/330(21%) → 149/382(39%). 응답에 조문 원문·개정 이력·서식 직다운로드가 실림.
- 지침 조문 인용이 현행 고시와 1:1 정합 — QC 가 NCR 에 §를 복붙해도 틀리지 않는다.
- sync 재실행으로 개정 추적 가능 (fetchedAt/verifiedAt 자동 기록). 단 **개정 자동 감지는 미구현** — 주기적 sync 재실행이 운영 의무.
- staging 이 git 에 전량 보관되어 repo 용량이 증가한다 (수 MB 수준 — 수용).
