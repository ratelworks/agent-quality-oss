## 2. Upstream Standards — Identifiers Only, No Full Text

This MCP server reasons over Korean construction **quality** standards. It
bundles **only identifiers and structural metadata** (titles, clause numbers,
section locators) — **never the full text** of the following third-party
standards, whose copyright belongs to their respective issuers:

| Material | Copyright holder | What this repo ships |
|---|---|---|
| KCS / KDS (국가건설기준, 표준시방서·설계기준) | 국토교통부 / 국가건설기준센터 | **Identifiers & section metadata only** (title, clause number). Redistribution of clause text is prohibited. |
| 건설공사 품질관리 업무지침 | 국토교통부 고시 (Ministry of Land notice) | Identifiers & scope only |
| KS 표준 (KS F 2402, KS F 2405 등) | 한국표준협회(KSA) / 국가기술표준원 | **Identifiers & titles only.** Full text requires a KSA license. |
| 건설기술 진흥법·시행령·시행규칙 등 법령 | 대한민국 (저작권법 §7 비보호) | Article identifiers & locators (freely citable) |

> **The OSS distribution contains no upstream clause text.** When a user needs
> the **full clause text** of KCS/KDS/KS, it must be obtained separately from
> the issuing body. The standards RAG (Phase 2+) operates **only on documents
> the user supplies locally**.

The bundled seed data in `src/ontology/data/*.json` carries `license` /
`redistributionNote` fields reflecting these constraints.

## 3. Required Attribution When Surfacing Standards

When you expose standard identifiers retrieved through this MCP to end users,
preserve the original attribution. A recommended citation is:

```
출처: 국가건설기준센터 (KCS/KDS) · 국토교통부 / 한국표준협회 (KS)
```

Each tool response includes a `basis[]` list and a `lineage` block — those
values identify the standard a statement is grounded in and are safe to surface
to users. Because no clause text is bundled, summaries generated by an LLM must
not be presented as if they **are** the upstream standard.

## 5. Disclaimers

- This MCP is a **domain-knowledge supply layer and draft-generation aid**.
  Outputs are not certified quality documents; responsibility for review,
  judgment, and on-site application rests with qualified quality-control
  personnel (품질관리자) and supervisors (감리원).
- Quantitative verdicts (slump / strength / air content ranges, etc.) reflect
  bundled public-standard values and must be confirmed against the
  project-specific mix design (배합설계서) and specification (시방서), which
  take precedence per the basis-priority rule.
- Standard and statute references are provided as **locators**; the legally
  binding text is the original issued by each authority.
